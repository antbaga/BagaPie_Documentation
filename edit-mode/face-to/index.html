Face To patterns

The Generate section of the D pie menu converts the selected faces into a pattern:

  • Face to Grid
  • Face to Paving
  • Face to Perforated Grid

  • Face to Plank

  • In Edit Mode, select the faces.

  • Press D and choose a pattern.
  • Adjust it in the operator panel at the bottom left.

As long as the operator panel is visible, you can change the pattern. Once you click elsewhere, the result is applied and can no longer be edited.

The settings match the parametric versions in the Object Mode pie. To keep a pattern editable on a whole object, use Paving, Grid, Perforated Grid or Plank from the J pie instead.
