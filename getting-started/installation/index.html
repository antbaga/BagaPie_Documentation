Installation

Install from Blender (recommended)

BagaPie is published on the Blender Extensions platform. Installing it from there gives you one-click updates.

  1. Open Edit > Preferences > Get Extensions.
  2. Search for BagaPie.
  3. Click Install.
  4. Save your preferences if they are not saved automatically.

BagaPie is also distributed on SuperHive, Gumroad and BlenderKit. It is the same add-on on every platform, but only the Extensions platform version updates from inside Blender.

Install from a ZIP file

If you downloaded the ZIP:

  • Drag the ZIP from your file browser into an open Blender window and confirm, or
  • Use Edit > Preferences > Get Extensions > menu (˅) > Install from Disk… and select the ZIP.

Do not unzip the file. Blender installs it directly from the archive.

Update

  • Extensions platform: open Edit > Preferences > Get Extensions and click Update next to BagaPie.
  • ZIP install: uninstall the previous BagaPie, restart Blender, then install the new ZIP.

First-time setup

These steps are optional, but recommended.

  1. Parametric Library. In the BagaPie preferences, open Assets and click Setup BagaPie's Parametric Library CC-0. This adds a BagaPie Modifier library to the Asset Browser. The Edit Mode pie menu (D) needs it, then a Blender restart. See Asset libraries.
  2. Group shortcut. If BagaPie offers Add Group Shortcut (in the panel, the pie menu or the preferences), click it to use Ctrl + G for BagaPie groups, then save your preferences. See Group.
  3. GeoPack location. Before installing a GeoPack, choose a folder for your packs in Preferences > GeoPack. See GeoPack.

Which version for which Blender?

Blender BagaPie
5.0 and newer BagaPie 11 (current 11.0.x builds)
4.2 to 4.5 BagaPie 10.x or the BagaPie 11 builds published for these versions
3.4 BagaPie 0.9.x.x; BagaPie Assets packs (.baga) are installed from the add-on preferences
3.3 BagaPie Modifier 0.8.x.x + BagaPie Assets 3.x.x
3.2 BagaPie Modifier 0.7.x.x + BagaPie Assets 3.x.x
3.1 BagaPie Modifier 0.6.x.x + BagaPie Assets 2.x.x
3.0 BagaPie Modifier 0.5.x.x + BagaPie Assets 1.x.x
2.93 BagaPie Modifier 0.3.x.x

The Extensions platform only offers you builds compatible with your Blender version.

Note

Scatter systems created with BagaPie 5.0 or older are not compatible with the current version.

Where to find it

  • 3D Viewport sidebar: press N and open the BagaPie tab.
  • Pie menus: J in Object Mode, D in Edit Mode, V for GeoPack. See Shortcuts.
