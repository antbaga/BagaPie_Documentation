Shortcuts

Default shortcuts, all in the 3D Viewport. You can change them in Preferences > Preferences > Menu Shortcuts.

Key Mode Action
J Object Mode Main pie menu: procedural tools
D Edit Mode (mesh, with something selected) Tools pie menu
V Object Mode GeoPack pie menu
Ctrl + Alt + J Any BagaPie panel as a pop-up
Ctrl + G Object Mode Create a BagaPie group
Alt + J Object Mode Duplicate the selected group
Alt + N Object Mode Duplicate the selected group, linked
Esc During Snap Asset Stop adding instances
Double click Object Mode (optional) Isolate a group or a group instance for editing; double click in empty space to leave

Group shortcut

Ctrl + G replaces Blender's own group shortcut in the 3D Viewport. If BagaPie shows Add Group Shortcut (or Add Group Key in the pie menu), the shortcut is not active yet: click it, then save your preferences. Otherwise it is reset at the next start.

Double click edit

Double click editing is a beta feature. Enable it from the group tools in the BagaPie panel (Double Clic Edit). See Group.
