# Release Notes

This documentation follows **BagaPie 11.0.11**. The full version history is on the [Blender Extensions platform](https://extensions.blender.org/add-ons/bagapie/versions/).

## BagaPie 11

**Node to Panel**

- Fully recursive: boxes in boxes, in rows, in boxes, and so on.
- Cleaner, more flexible modifier interfaces.

**Scatter presets with GeoPack**

- Save complete scatter setups as presets.
- Export and share them as `.geopack` files; assets are packed automatically.
- Previews are generated from the current view.

**Asset Browser panel**

- Displays all scatter layers.
- One-click scatter from the selected assets.
- Per-asset controls: proxy, bounds, select, remove.
- Easy layer renaming.

**Group system rewritten**

- Groups inside groups.
- **To Instance** in one click; switch between group and instances.
- Dynamic bounding box.
- **Ctrl + G** to create a group, double click to edit (beta).

**20 new tools**

- Face to Grid, Face to Paving, Face to Perforated Grid, Face to Plank.
- Window Modern, Window Classic, Door Simple, Door Double.
- Cable Creator, Bool Through, Tessellate, Insert Circle.
- Array Along Shape, Bolt Corner.

**Scatter improvements**

- Improved preview generator.
- Snap Asset uses the object offset, Bevel Weight and Vertex Crease.
- UI fixes in Scatter Paint and a simpler Scatter panel.

Plus many bug fixes and UI improvements.
