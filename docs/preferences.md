# Preferences

Open **Edit > Preferences > Add-ons**, find **BagaPie** and expand it. Save your preferences after changing them.

## GeoPack

Pack location, installed packs, pack creation and storage. See [GeoPack](geopack/index.md) and [Create a pack](geopack/create.md). The **?** button shows a short guide for using or creating packs.

## Preferences

**Menu Shortcuts**

| Item | Default |
| --- | --- |
| Main Pie (Object Mode) | J |
| Tools Pie (Edit Mode) | D |
| GeoPack Pie (Object Mode) | V |
| GeoPack Icon Scale | 7 |
| Group Shortcut | Ctrl + G (use **Add Group Shortcut** if missing) |
| Main Panel (Popup) | Ctrl + Alt + J |
| Duplicate Group: Simple / Linked | Alt + J / Alt + N |

**GeoPack Scatter Icon Generator Settings**: icon resolution (256 px), render samples (64), exposure, ozone, sun intensity, sun elevation and rotation, camera default focal (80 mm), use the 3D view focal length, and generate an icon by default when saving a scatter preset.

**Dev**: **Enable Experimental Features** (work in progress, for testing only) and **Debug Mode**.
